# Agent instructions

This repo is a fork of `JosiahHands/joPortfolio`. Cloudflare deploys the live site from `main` in `JosiahHands/joPortfolio`, not from this fork.

## Pull requests

When you edit this repo and are asked to "make a pull request", open it from this fork into `JosiahHands/joPortfolio`, with base `main`:

```sh
gh pr create -R JosiahHands/joPortfolio --base main --head Wardcode-frame:<branch>
```

Do not merge it. The owner reviews and merges every pull request.
